# 探索しない枝のルール

総当たりの前に「やるまでもない枝」を外すための共通ルール表。本体は`scripts/prune-rules.mjs`で、[妨害数の評価器](INTERRUPTION_EVAL.md)とリプレイ再現（`scripts/import-replays.mjs`）が同じ表を使う。

ユーザーから「この手は考えなくていい」と指摘されたら、その日付と理由を添えて1行ずつ足す。ルールで外した手は「調べていない」のであって、「成立しない」と証明したわけではない。

2026-11-08に「召喚が残っているのにアコード・トーカー①を使わない」を入れたが、①自体が墓地の攻撃力2300のサイバース族を特殊召喚するため誤りで、リプレイ2本の最後の召喚を止めていた。外した。

## カード効果ごとの対象

| カード | 外す対象 | 指示日 |
| --- | --- | --- |
| S:Pリトルナイト① | 自分のM∀LICEカード以外（相手のカード、M∀LICE以外） | 2026-11-08 |
| S:Pリトルナイト② | 自分側がM∀LICE以外の組。相手モンスターとの組は残す | 2026-11-08 |

## 展開中の一般ルール

| ルール | 理由 |
| --- | --- |
| リンク素材の「解除」を選ばない | 選び直しは「選択」だけで届き、解除は同じ選択への往復になる |
| デッキ・手札・墓地・EXの同名カードは1枚として扱う | どのコピーを選んでも結果が同じ |
| 召喚が残っているのにターンを終えない・バトルフェイズへ進まない | 展開途中で止める理由がない |
| 霆王の閃光・霊王の波動・聖王の粉砕を展開中にセットしない | 手札から使うカードで、セットしても展開が進まない |

## リプレイ再現だけのルール

- リプレイで一度も動かないカードの召喚・発動・セットは試さない。
- 置き場所は、リプレイでそのモンスターを置いたゾーンだけを試す。
- リンク素材は、リプレイがその召喚の直前に場から送ったモンスターだけを選び、そろったら確定する。
- 手札を捨てる選択では、リプレイでこの後使うカードを後回しにする。
