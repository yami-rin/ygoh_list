# 妨害数の評価器（土台）

[展開精査のゴール](OPENING_REVIEW_GOAL.md)の「評価器を先に修正する」に対応する最初の実装。旧`openingScore`のカード固定点は使わない。
本体は`scripts/interruption-eval.mjs`、回帰テストは`tests/interruption-eval.test.mjs`。

## やること

1. 保存ルートを実coreで再生し、自分の最終盤面が保存値と一致することを確認する。
2. 相手に固定の手札を持たせ（シナリオ）、決定的な方針で相手ターンを実行する。
3. ルート終了後の自分の判断（チェーン発動・対象・効果の選択肢）を全分岐で探索し、相手ターン中に解決できた妨害の最大数を求める。

妨害は「自分のチェーンが解決している間に起きた、相手への干渉」を1回と数える。干渉として扱うのは次の3つ。

| 種類 | 判定 |
| --- | --- |
| negate | 相手のチェーンが無効になった（`CHAIN_NEGATED`／`CHAIN_DISABLED`） |
| remove / grave / hand | 相手の場・墓地・手札のカードが別の場所へ動いた（`MOVE`） |
| disable | 解決後に相手モンスターが効果無効状態になった（`STATUS_DISABLED`） |

1回の解決で複数枚に干渉しても1回と数え、対象数は別に記録する。素材供給やリンク召喚だけ（I:Pの発動など）は、それ自体では数えない。共有資源や名称制限で両立しない効果は、実際に順番どおり解決させるため同時には加算されない。

## 探索の削り方

- 置き場所（ゾーン選択）は最初の合法ゾーンに固定する。リンク先が妨害数を左右する盤面では過小評価になりうる。
- デッキ・手札・墓地・EXの同名カードは、選択肢として1つにまとめる。
- 同じ盤面・同じ選択要求・直近のチェーン終了以降の同じ入力に、それまで以下の妨害数でたどり着いた枝は打ち切る。
- `TARGET_RULES`に、カード効果ごとの無駄な対象を登録する。該当する対象しか残らない枝は探索しない。
  - S:Pリトルナイト（2026-11-08のユーザー指示）：①の除外先は自分のM∀LICEカードだけ。②は自分のM∀LICE＋相手モンスターの組を残し、自分側のM∀LICE以外を含む組は探索しない。

## シナリオ

| 名前 | 相手の手札 | 相手の方針 |
| --- | --- | --- |
| `malice-mirror` | M∀LICE IN UNDERGROUND、バックアップ＠イグニスター、White Rabbit、Cheshire Cat、テラ・フォーミング | 効果発動→召喚→特殊召喚の順で使える行動を最大12回。自分のターン1では誘発を使わない。各選択は最初に受理された選択肢 |

相手は最善手を打たない固定の方針であり、結果は「このシナリオで実際に解決できた妨害数」である。全対面での妨害数や最大性の証明ではない。

## 未対応

- 相手のバトルフェイズと攻撃への干渉（リングリボー等）。相手は攻撃しない。
- 手札誘発を相手が使うシナリオ（土台の2つ目で扱う）。
- 効果無効の判定は解決直前後の状態照会に依存し、同じ処理単位で状態が変わる場合に見落とす可能性がある。
- 自動入力（`opening-policy.mjs`）の候補順位への接続。
