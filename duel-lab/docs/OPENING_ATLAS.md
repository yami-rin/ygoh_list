# M∀LICE 初動アトラス

固定構築の2枚手札を選び、保存済みの無ドロー手順を盤面・手札・墓地・除外・LP付きでたどる静的ビューアー。既知の手順が実際にどの選択を通ったかを読むための道具です。

## 生成と確認

通常のduel-lab依存・カードデータ・固定coreがそろったcheckoutで実行します。追加のnpm依存はありません。

```powershell
npm run openings:atlas
```

`runtime/opening-atlas/<生成時刻>/` にHTML、表示データ、照合結果、生の再生記録を保存し、出力パスを表示します。常に新しいフォルダーへ書きます。出力先を指定する場合も、`runtime` 配下の未作成ディレクトリに限定します。

```powershell
node scripts/build-opening-atlas.mjs --output runtime/my-opening-atlas
node scripts/build-opening-atlas.mjs --verify runtime/my-opening-atlas
```

`--verify` は、元のソース・ルール資産のハッシュ、配布ファイル、生の再生記録、全盤面、配置先、枚数を再照合します。同じソース・構築・ルール資産が必要です。変更済みの場合は対応するcheckoutに戻すか、新規生成してください。既存フォルダーを上書きするオプションはありません。未完の出力には`BUILDING.json`、失敗時には`FAILED.json`が残り、成功時は`COMPLETE.json`を作ります。

フォルダーをローカルHTTPサーバーで配信します。次は空いているポートで、サーバーを自分のPCだけに公開する例です。

```powershell
python -m http.server 8769 --bind 127.0.0.1 --directory runtime/my-opening-atlas
```

`http://127.0.0.1:8769`を開きます。外部通信・認証・自動対戦の起動は不要です。生成物はclassic scriptの静的HTMLですが、ローカルファイル直開きの実行確認は検証用ブラウザーのURL制限により未実施です。

## 操作

- 2枚を指定して表示。採用が1枚のカードを2枚目にも選ぶことはできません。
- 日本語・英語・カードIDのAND検索。NFKCで全角英数字にも対応します。
- 最初／前へ／次へ／最終盤面、操作一覧、スライダー、自動再生。手動操作・カード本文表示・ページ非表示で自動再生を止めます。
- 盤面・手札・墓地・除外のカードから日本語本文を表示。Escで閉じると、元のカードにフォーカスが戻ります。
- `#pair=<昇順のカードID2枚>&step=<操作番号>`で再生位置を指定。説明へのページ内リンクは選んだ手札を保持します。

## 根拠と限界

`openingSources()`の明示された手順だけを`loadOpeningTemplates()`で検証し、`bestOpening(..., {maxCandidates: Infinity})`で各固定2枚組の適合候補をすべて試します。残すのは既存の`openingScore`で選んだ1手順です。これは実アプリの24候補上限とは異なります。

`handUsage()`による「2枚とも手札を離れた」「片方が残る1枚手順」「個体を断定できない」を区別します。罠セットのみ、通常召喚のみ、手札コストの手順も含み、手順の適用率を初動成功率・勝率として扱いません。評価値は既知候補間の比較用で、妨害貫通や全合法手の最適性を証明しません。

未知ドローの結果、相手の妨害、全5枚手札は対象外。実際の追加手札によって必要なデッキ内カードや確認履歴が変わるため、2枚で通る手順でも5枚では適用できない場合があります。既存の初動集とネイティブ自動対戦の動作は変更しません。

すべての表示盤面は、トレースに保存した実coreの状態と照合します。メイン＋EXの総枚数・同名カードの上限も検査します。現在の表現で保持できないトークンやX素材などが必要になれば、生成を失敗させて表現を拡張する必要があります。静的表示に攻撃力変化・使用済み効果・リンク先などの完全なゲーム状態は含めません。

配置先ラベルはモンスター／魔法・罠の種類と、その種類内のmaskを併用します。選択後、または直後の表示形式選択後に、実際の盤面の対応枠へカードが入ったことを照合します。YESNOの説明はsemantic requestのnative 4bit形式で読み、modern 20bit形式と混ぜません。

## 検証

生成時に全候補適用・全盤面照合を実行します。`verification.json`に実件数、`COMPLETE.json`に表示ファイルのSHA、`traces/`に元の再生記録を保存します。途中にソースや全Luaを含むルール資産が変わった場合は失敗します。

```powershell
node --test tests/opening-atlas.test.mjs
```

テストは実coreから保存した短い手順、魔法・罠配置の回帰、質問ID、盤面と選択の不一致、出力パスの上書き・外部リダイレクト拒否を対象にします。大量の生成データはGit対象外の`runtime`に保持します。
