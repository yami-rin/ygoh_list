# 展開精査のゴール

2026-09-10のユーザー指示に基づく、今後の展開精査の作業基準。以前の「合法に動けるルートの収集」を主目的とする方針を改める。

## ゴール本文

固定M∀LICEの全合法2枚組333種類について、相手ターンに実行可能で相互に両立する妨害を複数構えられる展開を探し、検証済みの候補間で妨害数と妨害の質を最大化する。実カード処理で発動条件・コスト・素材・対象・名称ターン制限・共有資源を確認し、実際の妨害解決まで検証する。単なる召喚成功、盤面のカード枚数、固定のカード点数を良い展開の証拠としない。条件付き妨害、後続、妨害を受けた場合の継続も区別して比較し、選んだ手順をMDPro3自動入力へ接続する。全333組の評価・根拠・未検証点を示し、必要なテストとnative検証、関連差分のcommit/pushまで行う。

## 範囲と前提

- 固定デッキ、合法2枚組333種類、先攻。残りの未知の初手３枚を利用できると仮定しない。
- 自分の不確定ドロー後は展開探索から除外し、引いたカードを都合よく指定しない。
- 妨害の検証は、到達した盤面から相手ターンへ進め、明記した相手の行動・対象を持つテスト局面で行う。相手の行動を知っていたことにして先攻ルートを選ばない。
- 「無妨害で構えられる妨害」と「自分の展開を止められた後に構え直せる妨害」は別の結果とする。
- 現在の全保存候補を見直す。旧採点で選ばれたbestだけが強い候補とは限らないため、必要な組では保存終端や代替ルートから比較候補を回収する。

## 妨害の数え方

１回の発動・適用で相手の行動や資源に干渉した機会を基本単位とする。無効、破壊、除外、バウンス等の種類、対象数、対象範囲、発動機会は別に記録する。１効果で２枚を除外した場合は「１回・２対象」であり、自動的に２妨害とは数えない。

素材供給、サーチ、I:Pによるリンク召喚などの準備だけには妨害数を与えない。その結果として相手のカードへ干渉する効果が解決した段階で数える。無効化とそれに伴う破壊も同一解決なら１回とする。

同じカード・コスト・素材を取り合う効果、いずれかしか使えない効果、同名ターン制限は同時加算しない。妨害を使った後の状態から次の妨害を順番に実行する。永続的な制限は独立した項目で示し、相手の行動回数だけ妨害数を増やさない。

各候補の評価には以下を残す。

| 項目 | 記録内容 |
| --- | --- |
| 実行確認数 | 指定した相手シナリオで連続して解決できた妨害数と入力・効果処理の証拠 |
| 条件付きの追加分 | 相手のカード種、墓地、発動タイミングなどが必要な効果。基礎数へ混ぜない |
| 排他関係 | 同じ素材・コスト・名称制限により併用できない効果と選択肢 |
| 質と範囲 | 無効／除去、対象の種類、対象数、永続制限、応答できない行動 |
| 後続 | 実際に残る手札・墓地・除外資源と次ターンの再始動手段 |
| 耐性 | どの具体的な妨害をどの地点で受け、何妨害まで立て直せたか |

## 候補の比較

まず、同じ相手シナリオ・前提で実行確認数を比較する。妨害数が同じ場合は対応範囲、条件の厳しさ、共有資源への依存、後続を比較し、優劣が一意でない候補は併記する。手順の短さはその後の比較条件とする。

複数シナリオの結果を示し、協力的な相手を仮定した最大値だけで順位を決めない。相手の具体的行動に依存するため、「必ずN妨害」「全対面で最大」「勝率が上がった」とは結果なしに表現しない。

## 実施順と完了条件

1. 評価器を先に修正する。I:P単体、素材供給を伴うI:P、共有資源で競合する妨害を区別する回帰検証を置く。
2. 保存候補を新基準で比較し、複数妨害へ伸ばせる組と候補が不足する組から追加探索する。訪問数や全応答列の消化を進捗の主指標にしない。
3. 各組に最終盤面・手順・妨害内訳・連続解決の証拠・前提・代替候補を記録する。「候補なし」「未検証」「確認範囲の最良」を区別する。
4. 自動入力の選択にも同じ評価基準を接続し、実際の手札で再生して条件が崩れた場合は再評価する。未検証の高得点で検証済み手順を置き換えない。
5. 関連test、保存ルート再生、代表native対戦で選択と入力を確認し、関連差分をcommit/pushする。

最大性を主張する組については、全候補の探索終了か、候補が超えられない上界と到達例の両方が必要。限られた候補間の最良を全パターンの最大と呼ばない。333組の品質評価の完了と、全応答木の探索完了は別に報告する。
