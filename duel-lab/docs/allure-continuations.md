# 闇の誘惑1枚からの後続探索

`scripts/search-allure-continuations.mjs` は闇の誘惑701後続を、共通 `search-kernel.mjs` v2へ渡す。元JSONの正順353、独立監査で解決した逆順345、同名DARK2枚のもう一方の手札indexを除外する3分岐を、それぞれ別ジョブとして扱う。ドットスケーパーの墓地誘発も省かない。

最初は正順353後続とセット／エンドの根枝を処理し、その後に逆順345と同名個体選択3を追加して既存枝より優先して初回配分した。実エンジンの初期メニューが「セット／発動／エンド」の3種類であることをassertしている。701後続すべての初回配分後は、根枝2つを含め703ジョブ、6,769ノード、258ジョブ完了、1,406終端、実行失敗0。追加した348枝にはそれぞれ最大4ノードを配分した（早く終了する枝はその時点で完了）。全探索の完了ではなく、7,692の未展開prefixと追加ドローの境界を保存している。

## 公平な再開

```powershell
node scripts/exhaustive-draws.mjs --audit-reverse
node scripts/search-allure-continuations.mjs --ms=24000 --nodes=6 --rounds=1
```

1プロセスの探索sliceは24秒、設定上の上限は29秒。起動するたびに保存したカーソルから再開し、このコマンドでは各未完ジョブへ最大6ノードを配る。途中で終端まで尽きたジョブは6未満で終了する。`--nodes=4` なら最大4ノードとなる。未訪問の追加枝を既存枝より優先し、701後続の一部だけへ大きな予算を投じない。完了ジョブを飛ばして次の一巡へ進む。

`runtime/search-allure/checkpoints/` には各ジョブの全入力prefix、元の残デッキ39枚の挿入順、未生成候補の位置、終端ルート、core拒否、失敗を残す。`scheduler.json` はジョブごとの累計と巡回位置を持つ。状態・checkpoint・要約は一時ファイルから置換し、同じ巡回を続けられる。

v2のLink素材の選択／解除や召喚取消は、共通kernelの監査済み条件でのみ省略する。盤面が似ている、カード名が同じ、強そうでないという理由で探索状態を統合していない。SUM/SORT修正後の新プロセスであることも確認する。

## ドローの条件と追加の偶然

最初の2ドローは名前別308組合せ、順序別608事象。正順353＋逆順345＋同名DARKの個体選択3を合わせて701後続になる。各ジョブの `orderedWeight/1482` がその順序のドロー事象の確率を表す。異名なら残コピー数の積、同名なら `n×(n−1)` が重みとなる。608事象に限って合計すると重みが1,482になることをassertする。複数の除外先は同じドロー事象に属する戦略選択なので、701ジョブの重みを単純合計して確率にしない。元の順不同の重み `weight/denominator` は出典照合用に残す。

闇属性がなければ手札全墓地送り後の誘発選択から始める。各ジョブは手札1枚と39枚の `deckOrder`、誘惑の発動から解決までの全入力履歴を持ち、履歴を保って再現する。逆順345件の公開状態hashは240件が正順と一致し、105件が相違した。一致したものも、将来の状態同値を証明したことにはせず別ジョブを維持する。未観測の残デッキ全順列や、その後の全ランダム結果まで探索済みとはしていない。

`stopOnDraw:true` は使用しない。既に起きた誘惑のドローまで検出して、後続の最初で止まるためである。代わりに元のドローイベント数を1（発動しない根枝では0）として記録し、それを超える新しいDRAWの後で停止する。

Cat／WHITE BINDERの任意ドロー選択では、直前の全残数・prefix・確率分布をchance-sourceとして保存する。「いいえ」は通常の行動分岐として探索し、「はい」は新DRAW後のfrontierへ渡す。両者へ50%ずつの確率を付けない。任意選択を経由しない新ドローも、直前のprefixと最後の入力を保存して、その時点のプールを再構築できるようにする。

`runtime/search-allure/draw-frontiers.json` はこの追加ドローの引継ぎ。偶然の分岐だけが残ったジョブは再訪して同じ停止地点を数え続けず、未完として保持する。新しい偶然を列挙・再生する工程が終わるまで、全完了とは報告しない。

ここでの各結果の重みは「誘惑1枚を手札、残り39枚を山札」にした研究fixtureの条件付き分布。実戦初手5枚の成功率や勝率へ転用しない。終端は自分の先攻1ターン目終了または決着までで、相手の妨害や次ターンの応答があれば別の未解決境界として扱う。
