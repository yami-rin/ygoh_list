# M∀LICE 早見表（先攻）

「何を持っていたら → 手順のどこが変わり → 盤面がどうなり → 相手ターンに何が起こるか」の形でまとめる。根拠（保存ルートの手順差分）は [CAUSAL.md](CAUSAL.md)、手順書は [GUIDE.md](GUIDE.md)。

## 1. 盤面の部品と、相手ターンに起こること

| 盤面に残すもの | 相手ターンに起こること |
| --- | --- |
| ネオテンペスト | 最初の窓で②→ディセーブルムを墓地へ → 魔法・罠を1回無効 |
| 墓地のコード・オブ・ソウル | 相手MPに③ → 素材が揃えばHEARTS（無効化されない除去）／ファイアウォール（バウンス）。ネオテン＋ウィキッドだけでは出せない |
| アコード（リンク先に自分のL） | 効果の発動を1回、無効にして除外 |
| 伏せGWC－06＋墓地のWR | WR蘇生→WR①でMTP－07セット→WRを除外してMTP（MHサーチ＋除去）→MHを相手MPに特殊召喚 |
| 伏せMTP－07＋場のM∀LICE L | サーチ＋フィールドのカード1枚除外 |
| リングリボー | 罠を1回無効にして除外 |
| 伏せた霆王の閃光 | 相手モンスター1体除外（伏せて撃てば属性の縛りなし） |

## 3. 2枚目を持っていたら何が変わるか

| 初動 | 2枚目 | どこが変わるか | 着地の変化 |
| --- | --- | --- | --- |
| Dormouse | ソウル | バックアップ②でソウルを捨てる → ネオテン②はドットを落とす → ドットがリングリボーに | ＋リングリボー |
| Dormouse | March Hare | TB－11の後、墓地のTB－11を除外してMH → MHをネオテンの素材に → 余ったバックアップがリングリボーに | ＋リングリボー |
| Dormouse | Cat | 伏せる予定のGWCを使い、Cat①で2ドロー | 伏せGWCを失って手札+2（損得は五分以下） |
| Dormouse | バックアップ | 手順内のバックアップを①で出すので同名に当たる | 変わらない |
| UG | バックアップ／Cat／WR | 手順のバックアップを①で出せば**通常召喚が余る** → 2枚目を出してリングリボー | ＋リングリボー |
| UG | ソウル | ソウルを体にしてHEARTS（GWCで蘇生したWR＋WHITE BINDER＋ソウル） | ネオテン→HEARTS、＋リングリボー |
| UG | March Hare | 墓地のUGを除外してMH → 体が増えてアコードの代わりにファイアウォール | アコード→ファイアウォール、LP +600 |
| WR | バックアップ | ウィキッド③のサーチが要らなくなり、ファイアウォールを作れる | ネオテン＋ファイアウォール＋リングリボー |
| WR | MH／Cat | 手順がデッキのMH・Catの①③を使い切るので同名に当たる | 変わらない（手札が増えるだけ） |
| バックアップ | March Hare | 捨て札をMH→ウィキッド③で除外→MH③で回収→ネオテン②のDormouseをMH①で除外→M∀LICE側へ | ＋アコード・WHITE BINDER・伏せGWC |

**型**：体が1つ余る→リングリボー。体が2つ余る／ソウルが体になる→HEARTS・ファイアウォール。手順の中で同名の①③を使っていれば、手札の2枚目は効かない。

## 5. 展開中の約束（理由つき）

- **うららの当たる効果を後に回す**：UG・Dormouse①（デッキから除外）は当たらない。TB－11・ウィッチ①・ウィキッド③・バックアップ②・Cat①（ドロー）・WHITE BINDER③は当たる。
- **同名の①③は1ターン1度**：黄金櫃・UGで出したM∀LICEの③は使用済み。後で罠のコストにしても戻らない。
- **余ったM∀LICE・バックアップはウィザード①・アコード①の前にリングリボー／S:Pへ**：ウィザード①でサイバース縛り（S:Pは戦士族）、アコード①で特殊召喚不可。アコードは①を使わずに出しておけば展開を続けられる。
- **ネオテン・アコードの素材は使い終えたM∀LICEから**：リングリボーとM∀LICE L（MTPの条件）は残す。
- **バックアップ②の捨て札と、自分のターンのネオテン②の行き先は終盤のスイッチ**：ソウルを持っていれば捨ててネオテン②はドットへ（リングリボーが増える）、MHを捨てればM∀LICE側の入口になる。
- **GWCは伏せたまま終える**（相手ターンのWR→MTP→MHの連鎖のため）。墓地にWRを残す。ネオテン②でEXから落としたLは蘇生できない。
- **最後に霆王・泡影を伏せる**（ゾーンが空いていれば）。霆王を手札から撃つとドット・ソウル・トランスコード・自分のうらら等が以後止まる。

## 6. 相手ターン

1. 最初の窓でネオテン②→ディセーブルム。
2. アコード②は相手の最初の要の発動に。
3. 伏せGWC→墓地のWR→WR①でMTP→WRを除外してMTP（MHサーチ＋除去）→MH①を相手MPに。
4. ソウル③は素材が揃っている時だけ（HEARTS＝M∀LICE含むちょうど3体、ファイアウォール＝2体以上でリンク合計4）。
5. 霆王を手札から撃つのは、ソウル③・ドット・自分のうららをもう使わない時だけ。
