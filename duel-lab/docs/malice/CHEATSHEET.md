## 2. 展開中の約束

- UG・Dormouse①（デッキから除外）はうららを受けない。サーチ・デッキからの特殊召喚（TB－11・ウィッチ①・ウィキッド③・バックアップ②）から先にうららが来る。
- M∀LICEの①③はカード名ごとに1ターン1度。黄金櫃・UGで除外したカードの③はその場で使う。
- ウィザード①の後はサイバース縛り、アコード①の後は特殊召喚不可：**余ったM∀LICEのリングリボー・S:Pはその前に**。
- ネオテン・アコードの素材は使い終えたM∀LICEから。リングリボー・M∀LICE Lは残す。
- 自分のターンのネオテン②はソウルを墓地へ。
- 最後に、魔法・罠ゾーンが空いていれば **霆王・泡影を伏せる**（伏せ霆王は属性の縛りなし）。

## 3. 誘発を受けたら

| 誘発 | 受け方 |
| --- | --- |
| うらら | 止まった所から、手札の2枚目（バックアップ・ソウル・MH・UG）で続ける。Cat①を先に使うと囮になる（最初の機会に撃つ相手） |
| 泡影・ヴェーラー | 召喚直後のDormouse・WRに来る。2枚目で別の起点を作る |
| 霊王 | M∀LICE③の特殊召喚に来る。UG＋ソウルでも0.5点まで落ちる最大の弱点 |
| ニビル | 5体目の召喚後。**自分の場に出たトークンをリンク・スパイダーにして続ける**。実戦で最も重い（アコードまで届く手札が55%→28%） |
| ドロール | 2回目のサーチから。M∀LICEは除外・特殊召喚で動けるので比較的軽い |

## 4. 相手ターン

1. 最初の窓でネオテン②→ディセーブルムを墓地へ（以後、魔法・罠を1回無効）。
2. アコード②は相手の最初の要の発動に。
3. 伏せGWC－06→墓地のWRを蘇生→WR①でMTP－07をセット→WRを除外してMTP－07（MHサーチ＋除去）→MH①で相手メインフェイズに特殊召喚。
4. ソウル③で相手メインフェイズにリンク3以上（素材が揃えばファイアウォールでバウンス）。
5. 霆王を手札から撃つのは、ソウル③・ドット・自分のうらら等をもう使わない時だけ。
