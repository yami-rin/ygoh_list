## 2. 基本の回し方

### 2.1 エンジンの核

1. **③の起こし方**（M∀LICEを除外する手段）：UG発動・Dormouse①（デッキから）・Cat①（手札から）・MH①（手札・墓地から）・罠3種の発動コスト（場から）・ウィキッド③のコスト（墓地から）・WHITE BINDER①（墓地から最大3枚）・S:P①（場・墓地）・黄金櫃（デッキ）・闇の誘惑（手札）・マグナムート/ドルイドヴルム（墓地）。
2. **③で何が起きるか**：WR・Cat・Dormouseは自身が出る（1ターン1度）。MHは除外状態のM∀LICEを手札へ（MH①でもう一度除外すれば、そのカードの③が再び…ただし同名③は1ターン1度）。L2種は900LPで復帰（BINDERはドロー付き、HEARTSは攻撃力2倍）。
3. **サイバース側**：最初のLを作る（リングリボー・デコーダー・アルミラージ・ウィッチ・S:P）→ウィキッドのリンク先に特殊召喚してバックアップをサーチ→バックアップ①で手札から出て②でウィザード等をサーチ→ウィザード①で墓地の闇サイバースと並べる→デコーダーを使い回しながらトランスコード・HEARTS・アコード・ネオテンへ。

## 3. 考え方

1. **妨害の数と質を最優先**。質＝①無効にできるか（アコード②・ディセーブルム・リングリボー）②除去か（HEARTS①・MTP－07・ソウル経由のL）③相手ターンに何度使えるか ④無効化されにくいか（HEARTSはリンク先が埋まっていれば無効化されない、MH②は対象耐性）。
2. **ケア**：1枚の誘発で全部止まる一本道を避ける。止められても困らない効果を先に使って誘発を引き出す（Astraの指示と同じ）。M∀LICEの「デッキから除外」はうららに止められない（うららの対象は手札に加える・デッキから特殊召喚・デッキから墓地）。止められるのはTB－11・バックアップ②・ウィキッド③・コード・マジシャン②・MTP－07・ネオテン②。
3. **リソース**：LPは300×③回数＋900×L③回数。8000から1500〜2100が普通。ドローはCat①・WHITE BINDER③。手札の誘発・霆王を残せるかも盤面の一部。
4. **相手ターン**：ネオテン②はディセーブルムを先に落としておかないと、相手の最初の魔法・罠に間に合わない（墓地にある状態で発動に対して除外するため）。相手のスタンバイなど早いタイミングで落とすのが基本（仮説、要検証）。
5. **後攻**：未調査。G・マルチャミーに合わせない、ニビル（相手の5回召喚後）、HEARTS・アクセスコード・S:Pでの捲りが候補。
