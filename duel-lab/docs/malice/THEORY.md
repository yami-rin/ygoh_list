# M∀LICE の考え方（検証データから）

数字は `scripts/malice-search.mjs` の静的見積もり（相手ターンに使える妨害の目安）。根拠の表は [HANDTRAPS.md](HANDTRAPS.md)・[EXTENDERS.md](EXTENDERS.md)・[ROUTES.md](ROUTES.md)、個々の裁定は [FINDINGS.md](FINDINGS.md)。
「代役」はリプレイで名前のない手札（霆王の閃光で代用、展開には使わない）。

## 1. 目標の盤面

- 誘発なしの到達点は 2.3〜3.6点：**ネオテン（相手ターンにディセーブルムを先に墓地へ）＋アコード（リンク先に自分のL）＋墓地にコード・オブ・ソウル＋伏せM∀LICE罠**。
- ソウルは自分のターンのネオテン②で落とす。相手ターンのネオテン②はディセーブルムに使う（各ターン1回なので両立する）。
- 余ったM∀LICEは、ウィザード①（サイバース縛り）とアコード①（以後特殊召喚不可）より**前に**リングリボー・S:Pにする（F9）。
- アコード①の蘇生数は空いているリンク先の数で決まる。並べる位置を先に考える（F11）。

## 2. 誘発を受けると何が起きるか（1枚初動＋代役3枚）

| 誘発 | 最悪の窓に撃たれた時の点（5本） | 最悪の窓 |
| --- | --- | --- |
| 灰流うらら | 0.0〜1.0 | 最初のデッキ参照：TB－11・ウィッチ①・コード・マジシャン②・ウィキッド③ |
| 無限泡影・ヴェーラー | 0.0〜1.0 | 召喚直後のDormouse・WR、ウィッチ・WHITE BINDER |
| 霊王の波動 | 0.0〜0.5 | M∀LICE③の特殊召喚、TB－11 |
| 屋敷わらし | 0.0〜1.8 | UNDERGROUNDの発動、ドットスケーパー、デコーダー |
| 幽鬼うさぎ | 0.0〜0.6 | 最初に場で効果を使ったM∀LICE |
| 朔夜しぐれ | 0.3〜1.0 | 特殊召喚した起点 |
| 霆王の閃光 | 0.5〜1.5 | 手札・墓地の効果を使った後の場のモンスター |
| ニビル | 0.0〜0.6 | 5体目の召喚の直後 |
| ドロール | 1.3〜2.0 | 2回目のサーチ（M∀LICEは除外・特殊召喚で動くので比較的軽い） |

→ **1枚初動は、ドロール以外の誘発1枚でほぼ止まる。誘発を受ける前提では2枚目が要る。**

## 3. 2枚目の価値（誘発を最悪の窓に受けた時、うらら・泡影・ドロール・霊王・ニビル × リプレイ5本）

| 2枚目 | 平均 | 最低 | 同じマスの代役 | 理由 |
| --- | --- | --- | --- | --- |
| バックアップ＠イグニスター | 2.04 | 1.31 | 0.67 | EXのサイバースが1体いれば手札から出て、闇サイバース（M∀LICE・ウィザード・コード・マジシャン）をサーチできる。M∀LICE側が止まってもサイバース側で続く |
| UNDERGROUND | 1.64 | 0.0 | 0.67 | デッキから除外（うららを受けない）で1体増える。UNDERGROUND始動とは名前が重なり無意味 |
| March Hare | 1.47 | 0.0 | 0.67 | 手札・墓地のM∀LICEを除外して自身が出る。墓地にM∀LICEがないと動けない（NS＋コード・マジシャンでは0） |
| White Rabbit・Cat | 約0.95 | 0.0 | 0.67 | ③・①が1ターン1度で、初動側の同名や同系統と重なる |
| コード・オブ・ソウル | 2.22 | 0.51 | 0.67 | Lが1体いれば手札から出る体。素材にして墓地へ行けば相手MPの③（リンク3以上のリンク召喚）まで残る |
| コード・マジシャン | 1.90 | 0.0 | 0.66 | Lがいれば手札から素材になり、②でドットスケーパーを落としてウィキッド③へ繋ぐ（NS＋コード・マジシャンでは2枚目にできない） |

→ **手札の2枚目はバックアップ・コード・オブ・ソウルを最優先で評価する（どちらも最低点が高い＝どの誘発でも何か残る）。M∀LICE始動ならMH・UG、サイバース始動ならUG。WR・Catの重ね引きは誘発への受けにならない。**
（ソウルの点にはソウル③の見積もり1点が含まれる。評価器での確認は [CALIBRATION.md](CALIBRATION.md)）

## 4. 展開順の原則

1. デッキから除外する効果（UNDERGROUND・Dormouse①）はうららに止められない。サーチ・デッキからの特殊召喚（TB－11・ウィッチ①・ウィキッド③・バックアップ②）は止められる（F2）。
2. うららはドローを含む効果（Cat①、WHITE BINDER③）にも撃てる（F3）。
3. 黄金櫃・UNDERGROUNDでデッキから除外したカードの③はその場で使う。後で罠のコストに使っても戻らない（F6）。黄金櫃は1枚初動としては弱い（代役版で1.31点）。
4. Cat＋MHは、最初にCat①でMHを除外して2ドロー→MH③でMH自身を回収（F10）。盤面・LPは同じで手札+2。
5. 自分の霆王・霊王を手札から撃つと、ドットスケーパー（地）・ソウル（炎）・トランスコード（地）・ファイアウォール（光）が使えなくなる。展開を終えた後か、使わない盤面でだけ手札から撃つ。

## 5. まだ分かっていないこと

- 誘発の窓を相手が最善に選ぶ前提で、こちらが順番を変えて被害を減らす手（現在の表は「ユーザーの手順のまま撃たれた後の最善」）。
- 後攻（[QUESTIONS.md](QUESTIONS.md) Q2）。
- 静的な点数と、相手ターンを実際に進めた妨害数（評価器）の対応。評価器は相手が旧プリセット固定手札で、現状では2〜3妨害で頭打ち。
