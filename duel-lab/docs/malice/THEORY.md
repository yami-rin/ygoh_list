# M∀LICE の考え方（検証データから）

数字は `scripts/malice-search.mjs` の静的見積もり（相手ターンに使える妨害の目安）。根拠の表は [HANDTRAPS.md](HANDTRAPS.md)・[EXTENDERS.md](EXTENDERS.md)・[ROUTES.md](ROUTES.md)、個々の裁定は [FINDINGS.md](FINDINGS.md)。
「代役」はリプレイで名前のない手札（霆王の閃光で代用、展開には使わない）。

## 1. 目標の盤面

- 誘発なしの到達点は 1.3〜3.6点（リプレイ5本、WR 1枚が最低）：**ネオテン（相手ターンにディセーブルムを先に墓地へ）＋アコード（リンク先に自分のL）＋墓地にコード・オブ・ソウル＋伏せM∀LICE罠**。
- ソウルは自分のターンのネオテン②で落とす。相手ターンのネオテン②はディセーブルムに使う（各ターン1回なので両立する）。
- 余ったM∀LICEは、ウィザード①（サイバース縛り）とアコード①（以後特殊召喚不可）より**前に**リングリボー・S:Pにする（F9）。
- アコード①の蘇生数は空いているリンク先の数で決まる。並べる位置を先に考える（F11）。

## 4. 展開順の原則

1. デッキから除外する効果（UNDERGROUND・Dormouse①）はうららに止められない。サーチ・デッキからの特殊召喚（TB－11・ウィッチ①・ウィキッド③・バックアップ②）は止められる（F2）。
2. うららはドローを含む効果（Cat①、WHITE BINDER③）にも撃てる（F3）。
3. 黄金櫃・UNDERGROUNDでデッキから除外したカードの③はその場で使う。後で罠のコストに使っても戻らない（F6）。黄金櫃は1枚初動としては弱い（代役版で1.31点）。
4. Cat＋MHは、最初にCat①でMHを除外して2ドロー→MH③でMH自身を回収（F10）。盤面・LPは同じで手札+2。
5. 自分の霆王・霊王を手札から撃つと、ドットスケーパー（地）・ソウル（炎）・トランスコード（地）・ファイアウォール（光）が使えなくなる。展開を終えた後か、使わない盤面でだけ手札から撃つ。

## 5. まだ分かっていないこと

- 誘発の窓を相手が最善に選ぶ前提で、こちらが順番を変えて被害を減らす手（現在の表は「ユーザーの手順のまま撃たれた後の最善」）。
- 後攻（[QUESTIONS.md](QUESTIONS.md) Q2）。
- 静的な点数と、相手ターンを実際に進めた妨害数（評価器）の対応。評価器は相手が旧プリセット固定手札で、現状では2〜3妨害で頭打ち。

## 7. 霆王の閃光の撃ち方（ユーザー回答 Q1：3枚採用）

本文：カード名1ターン1枚。相手が手札・墓地でモンスター効果を使ったターンだけ手札から撃てる。相手モンスター1体を除外。**自分の墓地に罠がなければ相手は手札からモンスター1体を特殊召喚できる**。**手札から撃つと以後のデュエル中、自分は地・水・炎・風のモンスター効果を使えない**。

このデッキで止まるもの：うらら（炎）・ドロール（風）・G（地）・ドットスケーパー（地）・コード・オブ・ソウル（炎、相手MPの③）・トランスコード（地）・アルミラージ（炎）・リンク・スパイダー（地）。止まらないもの：M∀LICE全員・バックアップ・ウィザード・コード・マジシャン・ネオテン・アコード・WHITE BINDER・HEARTS・ディセーブルム・リングリボー・デコーダー・ウィキッド（闇）、ファイアウォール（光）。

指針：
1. **先攻1ターン目の最後に、魔法・罠ゾーンが空いていれば伏せる**。伏せて相手ターンに撃てば、手札からの条件も属性の縛りもない。最終盤面で使う魔法・罠ゾーンは0〜1枠（伏せGWC/MTP）なので場所はある。エンジンでは伏せた霆王が相手ターンに発動でき、March Hareを除外した（`malice-dormouse-set-spark`）。ただし評価器（user-mirror、1000手順）の妨害数は伏せない版4・伏せた版3で、探索の打ち切りによる揺れの範囲（伏せた版は伏せない版の手をすべて選べるので、本来は下回らない）。
2. 手札から撃つのは「このデュエルでもうソウル③・ドットスケーパー・自分のうらら等を使わない」と言える時だけ。相手ターンにソウル③で動く盤面（ソウルを墓地に落とした盤面）なら、ソウル③を使った後に撃つ。
3. デメリット（墓地に罠がないと相手に特殊召喚を許す）は、展開でTB－11・GWC－06・MTP－07を使っていれば起きない。保存ルート25本中、墓地に罠がない盤面は WR＋MH・MH＋MH・Cat＋Cat の3本（バックアップ1枚初動は②で霆王を捨てれば満たす）。
4. 自分の1ターン目に相手が手札誘発（うらら・G等、手札・墓地のモンスター効果）を使えば手札から撃てるようになるが、相手の場にモンスターがいないことが多い。ニビルを受けた後のニビル本体は対象になる。

## 8. 相手ターンの動き（評価器の最善手順から、`scripts/malice-opp-turn.mjs`）

上位3本（Dormouse＋ソウル、Cat＋MH R1b、NS＋コード・マジシャン；相手＝ユーザーのデッキ、いずれも妨害4）で共通していた順番：
1. **最初の窓（相手のスタンバイ等）でネオテン②→ディセーブルムを墓地へ**。以後、相手の魔法・罠の発動を1回無効にできる（実際に霆王の閃光を無効）。
2. **アコード②は相手の最初の要の発動（UNDERGROUNDの発動）に使う**（リンク先のLをリリース）。
3. **伏せGWC－06でWRを蘇生 → WR①で墓地にないM∀LICE罠（MTP－07）をデッキからセット → WR自身を除外してMTP－07をその場で発動**：MHをサーチし、場のM∀LICE Lがいれば相手のカードを1枚除外。サーチしたMHは①で相手のメインフェイズに特殊召喚できる。伏せGWCは「WR→MTP→MH」の3段に化ける。
4. リングリボーは相手の罠（TB－11・霆王）を無効、WHITE BINDERはGWC等で除外→③復帰→①で相手の墓地の罠を除外。
5. ソウル③は相手メインフェイズにリンク3以上を出す：素材が揃えばファイアウォール（リングリボー等と相互リンクでバウンス）。

→ 伏せGWC－06は「墓地のWR」があると強い。WRを素材や罠のコストで墓地に置いて終える盤面を選ぶ。

## 9. 実戦の5枚手札でどうなるか（[SAMPLE.md](SAMPLE.md)、無作為80手札、誘発ありは各40手札）

- ネオテンペストまで届く手札 **83%**、アコードも並ぶ手札 50%。点（手札誘発込み）は4.5以上が18%、3.5〜4.5が40%、平均3.59（蘇生制限・ソウル③の採点訂正後に全80手札を再採点）。
- 低かった手札（2.3〜2.7点）は、M∀LICEモンスター・UNDERGROUND・バックアップ・ソウル・コード・マジシャンのどれも持たない手札（例：ウィザード＋GWC＋泡影＋墓穴＋霊王、闇の誘惑＋ドルイドヴルム＋誘発3枚）。このデッキの事故は「初動札0枚」がほぼ全て。うち2手札は全探索が完走して事故と確定（ウィザード＋GWC＋泡影＋墓穴＋霊王→リングリボーのみ、闇の誘惑＋ドルイドヴルム＋泡影＋うらら＋G→展開なし。闇の誘惑の2枚は代役順で固定）。コード・マジシャン＋闇の誘惑＋ウィザード＋アトラクター＋MTPは300秒でネオテン＋バックアップまで（打ち切り）。
- 初動札が1枚でもあれば、手札の誘発を合わせて3.5点以上がほとんど。上位は UG・Dormouse・バックアップ・ソウルを2枚以上含む手札（5点前後）。
- 相手がうらら・泡影を1枚持ち最初の機会に撃つ場合：平均点 3.59 → 3.07（うらら）／3.16（泡影）、ネオテン到達 83% → 68%／60%、アコードまで 50% → 43%／40%。1.5点未満まで落ちる手札は少ない（1〜2/40）。誘発1枚は「盤面を1段下げる」程度で、止まり切るのは初動札1枚＋誘発以外の手札のとき。
- 誘発の種類別（最初の機会に撃つ相手）：平均点 なし3.59／うらら3.07／泡影3.16／霊王2.95／**ニビル2.71**。ニビルと霊王が重く、アコードまで届く手札はニビルで28%（なし50%）、ネオテン到達は霊王で53%に下がる（5体目の召喚後に場を流され、アコードの素材が揃わない）。霊王はM∀LICE③の特殊召喚を止めるため到達率の低下が最も大きい。
