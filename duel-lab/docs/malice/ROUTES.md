## 改善候補（ユーザーの手順を案内にした探索で発見、各300秒）

### R1 Cat＋March Hare：先にCat①でMHを除外して2ドロー（`malice-cat-hare-plus`）【推奨：ユーザー回答 Q4】

1. Cat を召喚 → **Cat①：手札のMarch Hareを除外して2ドロー**。
2. **MH③（300LP）：除外されたMH自身を対象に手札へ戻す**。
3. あとはユーザーの手順どおり（Catでリングリボー → MH①でCatを除外して特殊召喚 → …）。元の手順で後半に使っていたMH③（ウィキッド③のコストでMHを除外した時の回収）は使わない。

結果：最終盤面・LP（6200）は元と同じで、**手札が2枚多い**。代償：Cat①の2ドローはうららの対象（[FINDINGS.md](FINDINGS.md) F3）なので、うららを先にCat①へ撃たれる窓が1つ増える。→ ユーザー確認 [QUESTIONS.md](QUESTIONS.md) Q4。

### R1b Cat＋March Hare 2段目：WHITE BINDER②を最後に回してMTP－07（`malice-cat-hare-plus-2`、3.91点）

R1の手順から次を変える：トランスコード②で戻すのはウィキッドではなくリングリボー → WHITE BINDERはDormouse＋ウィザード＋リングリボーで出す（①でリングリボーを除外）→ **②は使わずに**TB－11のコストでWHITE BINDERを除外（③で復帰＋1ドロー、TB－11でMHをリクルート）→ MH＋WHITE BINDER＋WRでアコード → アコード①でWHITE BINDERを蘇生 → **ここで初めてWHITE BINDER②を使いMTP－07をセット**（場にM∀LICE Lが残るので相手ターンにサーチ＋除去になる）。
最終：アコード＋WHITE BINDER（アコードのリンク先）＋ネオテン＋伏せMTP－07、LP 6200。トランスコードは残らない。
妨害評価器（200手順）：ユーザーの手順 2 → R1b 4（評価器の数は引いたカードにも左右される点に注意）。
誘発を最悪の窓に受けた時（[HANDTRAPS-SAVED.md](HANDTRAPS-SAVED.md)）も、ユーザーの手順より崩れにくい：うらら 1.01→1.61、泡影 1.01→1.61、霊王 0.51→1.11、ニビル 0.01→0.61、ドロール 2.01→1.61。
→ **Cat＋March Hareの推奨ルート**（ユーザー確認待ち：Q4）。

### R2 Dormouse 1枚：GWC－06をこのターンに使う（`malice-dormouse-gwc-now`）

伏せて終わるGWC－06を自分のターンに使い（WHITE BINDERを除外→③で復帰＋1ドロー、Catを蘇生してネオテンの素材に）、リングリボーを場に残す。ネオテン・アコード・ソウルは同じ、伏せGWCなし、LP 7100→6200、手札+1。妨害評価器（相手＝旧プリセットのミラー、4000手順）では元と同じ妨害2。**相手＝ユーザーのデッキ（user-mirror、200手順、引いたカードは使わない）では元の手順が妨害4、R2は妨害3** → 伏せGWC－06を残す元の手順のほうが良い（伏せGWCからWHITE BINDER・HEARTSを相手ターンに動かせるため）。→ Q3。

### R3 NS＋コード・マジシャン：WHITE BINDER①の使い方（`malice-ns-codemagician-plus`）

最初のWHITE BINDER①は使わず、アコード①で蘇生したWHITE BINDERの①で墓地のWRとMHを除外 → MH③（300LP）でMHを手札へ。盤面は元と同じ、LP 6800→6500、手札にMH（相手MPにも①で出られる）。

### バックアップ1枚（`malice-open-30118811`、LP 8000のまま）

バックアップ召喚 → ②でコード・マジシャンをサーチ（代役を捨てる） → バックアップでリングリボー → リングリボー＋手札のコード・マジシャンでウィキッド → コード・マジシャン②でドットスケーパーを墓地へ → ドットがウィキッドのリンク先に出て、ウィキッド③（コード・マジシャンを除外）で2枚目のバックアップをサーチ → バックアップ①で特殊召喚 → ドットでデコーダー → デコーダー＋ウィキッドでトランスコード（デコーダー蘇生）→ トランスコード②でリングリボー蘇生 → バックアップ＋デコーダー＋トランスコードでネオテン → ネオテン②でソウルを墓地へ。
最終：ネオテン＋リングリボー、墓地にソウル。M∀LICEを1枚も使わないので、うららの窓はバックアップ②・コード・マジシャン②・ウィキッド③・ネオテン②。

読み方：UNDERGROUNDかDormouseを含む2枚は3.3〜3.8点で安定。WR 1枚・WR＋MHはネオテンより HEARTS＋ファイアウォール／S:P の方が点が高い（ネオテン＋ウィキッドではソウル③のリンク先がない）。WRは2枚目がMH・Catだと伸びない（③・①の名前の重なり）。MH・Catの同名2枚は初動にならない。
