# 固定M∀LICEプリセットの非M∀LICEモンスター初動

2026-09-08。対象は `preset.json` のメイン40枚・EX15枚に含まれる、M∀LICE以外のメインモンスター全13種類。カードテキストと実ルールコアの合法選択を照合し、1枚の小展開8本、追加捨て札を使う展開2本、M∀LICE捨て札を使う中間展開1本を記録した。

ここで「1枚」は、そのカード以外の初手を使わず、先攻・空盤面・空墓地から動くことを指す。手札フィクスチャは元のメインデッキから該当枚数を抜いて作成する。開始ドローは0枚であり、通常の初手5枚の残り4枚やランダムドローを使った展開として扱わない。相手は妨害を行わない。

## 1枚だけで検証した有用な到達先

| 手札 | 検証したルート | 到達先の意味 |
|---|---|---|
| ドットスケーパー | 通常召喚 → デコーダー → ドット蘇生 → S：P | S：P単騎。相手の効果発動に反応する一時除外の準備。M∀LICEへのアクセスはない |
| ドットスケーパー | 通常召喚 → デコーダー → ドット蘇生 → リングリボー | リング＋デコーダー。罠無効用のリングと、次のリンクに使える体を残す |
| ドットスケーパー | 通常召喚 → アルミラージ → ドット蘇生 → リングリボー | リング＋アルミラージ。罠無効と効果破壊への保護を用意する |
| ドットスケーパー | 通常召喚 → デコーダー → ドット蘇生 → ウィキッド | 破壊耐性を持つウィキッド単騎。この手札ではリンク先への追加特殊召喚がないので検索まで進めない |
| バックアップ | 通常召喚 → コード・マジシャンを検索し、そのまま捨てる → ドットを墓地へ送り蘇生 → デコーダー＋リング | 追加捨て札なしで2体を作れる。M∀LICE本線の初動とは分ける |
| バックアップ | 上記の2体でウィキッド | ウィキッド単騎。コード・マジシャンの制約によりS：Pは選べないことも実コアで確認 |
| ウィザード | 通常召喚 → リングリボー | 罠無効用のリンク1。手札からの自己特殊召喚は空盤面では使えない |
| コード・オブ・ソウル | 通常召喚 → リングリボー | 罠無効用のリンク1。墓地の相手ターンリンク効果には別途素材が必要 |

8本とも最終手札0枚・LP8000/8000。いずれも「1枚でM∀LICEの通常展開に入る札」の枚数へ加える意味ではない。ウィキッド単騎は防御的な到達先であり、それだけで能動的な妨害が完成するとは評価していない。

## バックアップの追加捨て札を区別する

**任意の捨て札1枚を使う場合**、検索したコード・マジシャンを保持できる。検証では灰流うららを捨て、バックアップをデコーダーに変換し、手札のコード・マジシャンを素材にウィキッドを出した。コード・マジシャンでドットを落としてウィキッドのリンク先に蘇生し、墓地の最初のバックアップを除外して2枚目のバックアップを検索・特殊召喚する。

この共通部分から、次の2本を検証した。

- ドット＋バックアップ → I：P。ウィキッド＋I：Pを残す。
- ウィキッド＋ドット → トランスコード、ウィキッド蘇生 → トランスコード＋ウィキッド＋バックアップでアコード、トランスコード蘇生。アコードのリンク先にリリース用のトランスコード1体を残す。

2本とも最終手札0枚・LP8000/8000。アコードの蘇生効果後はそのターン特殊召喚できない。これらは**バックアップ＋追加捨て札**であり、真の1枚初動には算入しない。使用した捨て札は灰流うららであり、捨てた場合の強制効果などが異なる全カードへの置換検証は行っていない。

**捨て札がM∀LICEモンスターの場合**は別の分岐になる。バックアップ＋Catの2枚で、Catを捨ててコード・マジシャンを保持し、ウィキッドの除外コストをCatにすることで300LPを払ってCatを帰還させた。そこからWHITE BINDER＋ドット＋バックアップ、GWCセットまでを検証した。最終手札0枚・LP7700/8000。これは追加展開の中間盤面であり、最適な最終盤面まで到達したという意味ではない。

任意の捨て札を使ったルートで、ウィキッドが都合よく墓地のM∀LICEを除外できると仮定してはいけない。コード・マジシャンで落としたカードがドットなら、その効果だけで同時にM∀LICEも墓地へ用意できるわけではない。

## 全13種類の分類

| カード | 分類 | 1枚・空盤面での位置付け |
|---|---|---|
| バックアップ＠イグニスター | 追加手札を使う初動／1枚の小展開 | 自身しか手札にないと検索札をそのまま捨てる。上述のドット経由の小展開は可能 |
| ウィザード＠イグニスター | 条件付き展開札 | EX由来サイバース＋墓地の闇サイバースが自己特殊召喚の条件。1枚では通常召喚→リンク1 |
| サイバース・コード・マジシャン | 条件付き展開札 | 場のリンクを素材にするときの手札素材。空盤面の合法な行動はターン終了のみ |
| ドットスケーパー | 1枚の小展開 | 蘇生で素材2体分。M∀LICEへの確定アクセスはない |
| コード・オブ・ソウル | 条件付き展開札 | 1枚では通常召喚→リンク1。自己特殊召喚・墓地効果には別途盤面が必要 |
| マルチャミー・プルリア | 手札誘発 | 自力での展開ではなく、相手の召喚によるドローに依存 |
| 幽鬼うさぎ | 手札・場の誘発 | 通常召喚して場に残す行動は可能だが、M∀LICEを展開する初動ではない |
| 灰流うらら | 手札誘発 | 通常召喚やアルミラージへの変換を展開初動には数えない |
| 増殖するG | 手札誘発 | 相手の特殊召喚によるドローに依存 |
| ドロール＆ロックバード | 手札誘発 | 相手のデッキからの手札追加が必要。通常召喚から本線には入らない |
| ディメンション・アトラクター | 手札誘発 | 墓地除外化を適用できるが、自身1枚からM∀LICEを出す効果ではない |
| 深淵の獣マグナムート | 条件付き展開札 | 墓地の光・闇が必要。空盤面・空墓地ではターン終了のみ |
| 深淵の獣バルドレイク | 条件付き展開札 | 墓地の光・闇が必要。空盤面・空墓地ではターン終了のみ |

誘発の「通常召喚→アルミラージ」といった弱い変換をすべて有用な定型ルートにはしていない。ドットの墓地からの蘇生と除外からの蘇生は、同一ターンに両方使えると仮定しない。今回のドットのルートはすべて墓地からの蘇生を1回だけ使う。

## 検証方法と限界

実行コマンド:

```powershell
cd C:\Project\card_manager_web\duel-lab
node scripts/research-cyberse-starters.mjs
```

`engine.mjs` から固定された実ルールコアを起動し、各行動を合法選択から選ぶ。生成時に応答拒否とスクリプトエラーがないこと、先攻メインフェイズ1であること、終着モンスター・手札・必要なセット札・LPを検査する。その後、初期状態から独立にリプレイして、全入力直前の状態ハッシュと最終盤面ハッシュの一致を確認する。

出力は `routes/cyberse-starters.json`。11本のルートに初期手札、全入力、最終盤面、LP、手札、ログを保存する。さらに全13種類について、初期の合法選択、発動を見送って進んだメインフェイズの合法選択、再生可能な確認記録を保存する。プリセットが変わるとハッシュ不一致でリプレイは停止する。

全合法入力木の総当たりや対戦勝率の測定ではない。召喚位置の同型分岐、意図的に損をする素材変換、全ての妨害への貫通、相手ターンの妨害効果の実発動、MDPro3ネイティブクライアントでの入力対応はこのファイルの検証範囲外。盤面が変化した場合は現在の合法選択との再照合が必要で、保存した入力番号を無条件に送ってはいけない。
