# 連鎖律（chain-code）カードイラスト制作指示 v2 — 見分けやすさ優先

ユーザー作成のオリジナル遊戯王風カード12枚のイラストを作り直す。v1（`PROMPT.md`）は同じテーマ内で色・構図・明るさがそろいすぎて、MDPro3の縮小表示（1枚約70×100px、イラスト約56px四方）で見分けがつかなかった。v2では **テーマの統一感は素材・モチーフ・紋章・画風で保ち、主色（キーカラー）・背景の明暗・シルエットをカードごとに変える**。

先に `STYLE-GUIDE.md` の「1」「2」を読むこと。下の割り当て表は `STYLE-GUIDE.md` と同じ内容。

## 出力

- 12枚。各 1024×1024 の正方形 PNG。保存先はこのフォルダ（`custom/art/`）の `<カード番号>.png`。このテーマの既存ファイルは上書きする（旧画像は統括側で退避済み）。**他テーマの画像には触れない。**
- 使った画像生成プロンプトを `custom/art/prompts.json` に上書き保存する（`{"<番号>": "...", ...}`、修正パスがあれば追記）。

## v2で必ず守ること

- 各カードの画像生成プロンプトの冒頭に、**主色・副色・背景の明暗・構図**を英語で明示する（例: `Dominant key color: vivid orange light filling at least 40% of the image. Secondary: white. Background: dark navy. Composition: ...`）。
- 主色が画面の40％以上（空・霧・炎・光・背景）を占めること。主色以外の強い色は副色1つまで。テーマ共通の素材色（下記）は残してよい。
- v1の世界観にある「色調」の記述は **素材色としてだけ** 使い、画面全体の色はこの表の主色に従う。
- v1では全員がシアンだったが、v2では **カードごとに鎖の光と電脳空間の色を変える**（表の主色）。白い装甲・白金・回路の線・鎖の輪はテーマ共通として残す。
- 種類ごとの描き分け：下級モンスター＝1体のキャラを全身か上半身で明快なシルエット／上級・EX＝画面いっぱいの派手な切り札（光背・翼・巨大さ）／魔法＝場所・道具・儀式（キャラは小さく）／速攻魔法＝動きの一瞬／罠＝発動の瞬間・断つ・止める場面。
- 縮小しても潰れない画風：公式カードイラスト風の丁寧なデジタルペイントは保つが、画面全体を細かい模様で埋めない。大きな色面2〜3個、主題と背景の強い明暗差、単純な背景。
- 文字・数字・ロゴ・署名・透かし・カード枠を入れない。既存の遊戯王カードやキャラクターに似せない。露出の多い衣装にしない。

## v1の世界観（モチーフ・素材・紋章はこれを使う）

- 光属性・サイバース族のテーマ。名前は「連鎖律（Chain Code）」。
- 「チェーン（効果の連鎖）が積み上がるほど力を増す」プログラム世界。チェーン2、3と段が重なるほど強い効果になる。
- 共通の見た目：
  - 白金（プラチナ）とシアンを基調に、少しの金色。光属性らしい明るく清潔な発光。
  - 光でできた鎖の輪（チェーンリンク）。輪に「1」「2」「3」のような番号の刻印や光るインデックスがあり、連なって上へ伸びる。
  - 回路基板の線、浮かぶコード記号（括弧 `{ }`、矢印 `→`、`::`、二進数風の点滅）、ホログラムの格子。
  - 背景は電脳空間。奥行きのあるデータの流れ、幾何学的な光のレール。
- モンスターは、処理の役割を体現したサイバース（電脳生命体・人型プログラム・機械精霊）。人間の顔はなくてもよい。全員が同じシリーズだと分かる共通デザイン（胸や頭部に鎖の輪の紋章、白い装甲とシアンの発光ライン）。
- 既存の遊戯王カードの絵柄、既存キャラクター（デコード・トーカー、@イグニスター等）に似せない。商標・ロゴ・実在の文字列を入れない。

## 生成後の確認

- 全12枚を並べて見て、**縮小したときに同じ色・同じ構図に見える2枚がないか** を確認する。あれば主色の面積・背景の明暗・シルエットを強めて作り直す。
- 原寸で、文字・記号の羅列・署名・透かし・カード枠・崩れた手足や顔がないかを確認し、あれば作り直す。
