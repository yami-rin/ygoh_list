# オリカのイラスト規則（見分けやすさ優先）

MDPro3のデッキ編集では1枚が約70×100px、イラストは約56px四方まで縮む。ここで見分けがつくことを最優先にする。
v1（`PROMPT*.md`）はテーマ内で色・構図・明るさがそろいすぎ、縮小すると同じ絵に見えた（例：業火葬11枚の平均色相がすべて3〜9°、神折11枚が26〜34°）。v2の指示書は `PROMPT-<theme>-v2.md`。

## 1. 遊戯王の実テーマに倣う考え方

- **統一感は「素材・モチーフ・画風・紋章」で保ち、色はカードごとに変える。** ドラゴンメイドはメイドごとに髪と竜の色、閃刀姫はレイ＝青・ロゼ＝赤で、リンク体は装備した武装の色になる。ティアラメンツ、スプライト、ラビュリンスも「同じ衣装系統・同じ紋章で、1枚ごとに違う主色」。
- **カードの種類で描く対象を変える。** モンスターはキャラ、魔法は場所・道具・儀式、罠は発動の瞬間。永続魔法・フィールド魔法は「場所」、速攻魔法は「動き」。
- **縮小しても形で分かる。** 縦長の人物、横長の獣、円形の紋章、俯瞰の舞台など、テーマ内でシルエットの型を散らす。

## 2. 全テーマ共通の規則

### 色

- 1枚ごとに **主色**（キーカラー）を1つ決め、画面の **40％以上**（空・霧・炎・光・背景）を主色で占める。副色は1つまで。残りはテーマ共通の素材色（下表「素材色」）。
- 主色は下の14枠から選ぶ。**同じテーマ内で同じ枠を2枚に使わない。** 色相が隣り合う枠（30°差）を同じテーマで使うときは、**背景の明暗を逆にする**（明／暗）。60°以上離れていれば明暗は自由。
- テーマ内で背景の明暗をおおむね半々にする。暗いテーマ（業火葬・宵刻刃・呪われた）でも「明」のカードは主色の光・霧・炎で画面を明るく満たす。

| --- | --- | --- | --- |
| R | 0° | 赤・紅 | crimson / scarlet red |
| O | 30° | 橙・朱 | vivid orange / vermilion-orange |
| Y | 60° | 金・山吹 | golden yellow |
| L | 90° | 黄緑 | lime / chartreuse |
| G | 120° | 緑 | emerald green |
| T | 150° | 翠・ジェード | jade / mint green |

| W | 無彩・明 | 白・白金 | white-out / pale platinum |
| K | 無彩・暗 | 黒 | near-black with one small accent |

### 役割と色の系統（目安）

- 切り札（各テーマの最上級・EXの頂点）は W（白い光背）か K（黒地に1点の強い光）で、他の色付きカードから外して目立たせる。
- 起点・サーチ・展開役は暖色寄り（R・O・Y）、妨害・除去・無効は寒色寄り（C・B・I）、墓地・除外・闇の効果は紫寄り（V・M・P）を優先する。ただし上の「同じ枠を使わない」「隣は明暗を逆」が優先。

### 種類ごとの描き分け

| 種類 | 描くもの | 構図 |
| --- | --- | --- |
| 下級モンスター | 1体のキャラを全身か上半身で | 主題が画面高の60〜80％。背景は単純なグラデーションか1つの大きな形 |
| 上級・EX（S・X・L・融合） | 大きく派手な切り札。光背・翼・巨大さ | 画面いっぱい、見上げる構図、放射・円形の光背 |
| 魔法（通常・永続・フィールド） | 場所・道具・儀式の情景。キャラは小さく | 横長の風景、俯瞰、建物や道具が主役 |
| 速攻魔法 | 技・動きの一瞬 | 斜めの動線、接写、残像 |
| 罠 | 発動の瞬間・罠が閉じる・攻撃を断つ場面 | 中央で何かを止める・断つ・包む |

### 縮小で潰れないための画風

- 公式カードイラスト風のデジタルペイントは保つ。ただし **画面全体を細かい模様で埋めない。** 大きな色面2〜3個と、明暗差のはっきりした主題のシルエット。
- 主題と背景の明暗差を強くする（暗い主題×明るい背景、または明るい主題×暗い背景）。
- 文字・数字・ロゴ・署名・透かし・カード枠を入れない。既存の遊戯王カードやキャラに似せない。露出の多い衣装にしない。

## 4. 生成後の確認

- テーマごとに、約70×100pxのカードに縮めた一覧画像と、2枚ずつの類似度（色相ヒストグラムの重なり・16×16グレースケールの相関・8×8カラー縮小の差）を作り、v1と比べる。
- 縮小一覧で2枚が同じに見えたら、主色の面積・背景の明暗・シルエットのどれが効いていないかを見て作り直す。
- 文字・枠・署名・崩れた手足や顔がないことを原寸で見る。
