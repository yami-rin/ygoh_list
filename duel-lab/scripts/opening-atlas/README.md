# M∀LICE 初動アトラス

1枚目と2枚目を選び、「この2枚の展開を見る」。採用枚数を超える同名2枚は選べません。「次へ」「最終盤面」、スライダー、操作一覧から盤面をたどれます。「自動で見る」は手動操作やカード本文を開くと止まります。カード本文はEscで閉じられます。

1操作には配置・対象選択・確認も含みます。召喚を選んでも、配置選択を終えるまではカードが手札にある表示が正常です。最終盤面は保存手順の停止点で、先攻Main 1の途中です。

固定構築の2枚組すべてに、既知の無ドロー手順の適合候補を上限なしで適用し、既存の盤面評価で選んだ1手順を表示します。罠を伏せるだけ・通常召喚のみ・もう1枚が残る1枚手順も含みます。「手順あり」は初動成功率や勝率ではありません。未知ドロー・妨害・全合法手・全5枚手札の網羅は範囲外です。追加手札で選択対象がデッキから消えるなど、実際の5枚では同じ手順が通らない場合があります。

データと全盤面の照合結果は `verification.json`、ソースと配布ファイルのSHAは `data.js` と `COMPLETE.json`、実coreの生の再生記録は `traces/` にあります。カード本文は生成時のローカルデータです。

外部通信なしの静的HTMLです。フォルダー全体をローカルHTTPサーバーで配信して `index.html` を開いてください。直開きにも対応するclassic script構成ですが、検証用ブラウザーのURL制限によりローカルファイルの直開きは未検証です。生成し直す手順は元プロジェクトの `docs/OPENING_ATLAS.md` を参照してください。
