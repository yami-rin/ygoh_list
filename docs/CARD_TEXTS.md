# カードテキストの補完

2026-09-07にローカルマスター14,274件を補完し、空欄0件、ペンデュラム380件を確認した。既存9列と行順が作業前と同一であり、WebのCSVパーサーでも全件のIDと本文が一致することを検証済み。

`scripts/fill_card_texts.py`は、`Untitled-1.py`と同じ遊戯王公式DBの検索処理を利用し、既存マスターの空の「カードテキスト」だけを補完する。名前・種族・レベルなどの既存列と行順は保持する。

```powershell
# 依存: requests / beautifulsoup4 / lxml
python scripts/fill_card_texts.py          # 取得と照合のみ
python scripts/fill_card_texts.py --apply  # 全件照合後に反映
python tests/verify_card_texts.py          # 外部通信なしの検証
```

公式DBの検索結果を100件ずつ取得し、カードIDと名前を照合する。未取得ID、名前不一致、空の本文があればCSVを変更せず終了する。途中結果は`TMP/card-text-fetch/`に保存する。同じキャッシュで再実行すると取得を再開できる。新しい情報を取得する際は`--cache-dir TMP/card-text-fetch-YYYYMMDD`で新しい保存先を指定する。既に本文が入っているカードは上書きしない。

ペンデュラムカードは`【ペンデュラム効果】… 【カードテキスト】…`の形式で両方を収録する。通常モンスターの説明も取得対象。公式の改行はスペースに置換し、既存Webの行単位CSV読込との互換性を保つ。CSV自体はUTF-8 BOM付きで、カンマ・引用符はCSV規則でエスケープする。

反映前のCSVはキャッシュ内の`master-before-日時.csv`へ保存する。取得件数・照合結果・取得元・反映前SHA-256は同じ場所の`report.json`に残す。元のCSVが実行中に変更された場合も上書きを中止する。

名前が異なる場合は、マスターの「読み方」と公式名、または同じカードIDの詳細ページの英語名を照合する。2026-09-07時点では英語名の省略・日本語名追加による10件の表記差を確認した。照合できた表記差は`verified_name_aliases`に記録し、マスターの名前は保持する。
